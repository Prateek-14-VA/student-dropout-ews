# Student Dropout Early Warning System

A machine learning-based web application to identify at-risk students early.

## Tech Stack
- Python 3.10
- Scikit-learn, XGBoost, imbalanced-learn
- SHAP for explainability
- Flask + SQLite
- HTML, CSS, Bootstrap
